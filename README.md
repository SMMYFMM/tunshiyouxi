# AbsorbGame

一款离线单机 2D「吞噬成长」类 Android 游戏。控制你的细胞在地图中吞噬食物和比你小的敌人，不断变大，同时躲避比你大的敌人。

## 特性

- 🎮 **纯本地运行**：无任何网络权限，完全离线
- 🤖 **本地 AI**：基于 FSM 状态机 + Utility AI 的 40 个 AI 实体，会觅食、追击、逃跑
- 🎯 **三档难度**：Easy / Normal / Hard，AI 感知范围和攻击性不同
- 💾 **存档系统**：自动保存（每 45 秒）+ 手动存档槽，支持读档续玩
- ⏸️ **暂停功能**：暂停时冻结所有游戏逻辑，支持后台自动暂停
- 📊 **实时排名**：显示玩家在所有实体中的排名
- 🔊 **音效与音乐**：可在设置中开关音乐、音效、震动、FPS 显示

## 操作

- 左下角虚拟摇杆控制移动方向
- 吞噬比你小的实体（食物 / AI）来增长体积
- 躲避比你大的 AI，否则会被吞噬

## 技术栈

- Java + OpenGL ES 2.0（自研轻量 2D 引擎）
- SpatialHash 空间分区优化碰撞检测
- Gradle 构建

## 构建

```bash
./gradlew assembleRelease
```

产物路径：`app/build/outputs/apk/release/`

## 要求

- Android 9（API 28）及以上
- 无需联网
